# Open Design handoff

The Open Design project is the visual source of truth for the weatherbridge_ai
template. Keep the original artifact and tokens here before adapting them into
`fe/`.

The React implementation must preserve the same tokens across landing, auth,
Keycloak theme overrides, and the protected workspace shell.

## Unified design system

Generated by Open Design run `bfeb2d29` (agent: opencode) on 2026-07-17.
Artifacts live in `artifacts/`:

- `tokens.css` — single source of truth: palette, type scale, spacing, radius,
  shadow, component primitives.
- `landing.html` — landing page entry.
- `auth.html` — React auth (login/register) entry screen.
- `keycloak.html` — Keycloak account-login mock, ported into
  `infra/keycloak/themes/weather-bridge/login/resources/css/weather-bridge-theme.css`.
- `auth-split.html` (Open Design project artifact) — split identity layout;
  login uses brand-left/form-right and registration reverses the direction.
- `keycloak-split.html` (Open Design project artifact) — Keycloak form surface
  that shares the same responsive breakpoints and transition choreography.

The implemented handoff is direct: landing CTAs invoke Keycloak with PKCE,
without a React intermediary screen. At 820px and below, the split layout
collapses to a compact brand bar above the form.

Token summary (mirrored into `fe/src/shared/styles/globals.css`):

- Deep canvas `#0B0E14`, panel `#121821`, raised `#1A2230`.
- Accent (primary signal): amber `#F2A93B`.
- Positive (status): teal `#3DD6A4`.
- Native system UI font (interface and Vietnamese copy) + native monospace
  font (weather data, labels, and deadlines); neither requires a network load.

## OpenCode connection

The project-local OpenCode config exposes the local Open Design daemon as the
`open-design` MCP server:

```text
http://127.0.0.1:7456
```

Start Open Design before starting or restarting OpenCode:

```bash
od --no-open
```

The repository workflow is available as `/design-sync`. It reads the active
Open Design project, pulls the complete artifact bundle, preserves the source
under this directory, and then adapts tokens into `fe/` and the Keycloak theme.
The MCP connection uses local process transport and stores no credentials in
the repository. If the daemon asks for authentication, complete that flow in
Open Design and restart OpenCode so its MCP session is rebuilt.
