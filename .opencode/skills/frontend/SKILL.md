# Frontend

Use feature-based composition: `app`, `pages`, `features`, `widgets`, and
`shared`. Keep design tokens centralized. Use `keycloak-js` with PKCE and keep
tokens in memory. Never add `localStorage` authentication state.

At the start of every frontend coding task, check
`third_party/ui-ux-pro-max-skill/skill/SKILL.md`. If the change affects UI,
components, layout, animation, charts, accessibility, or user interaction, read
and apply that skill before editing.
