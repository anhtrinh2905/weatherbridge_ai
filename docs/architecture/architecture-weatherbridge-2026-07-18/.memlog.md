# Architecture Spine — Working Memory (append-only)

## Inherited / ratified from EXISTING CODE (brownfield — [ADOPTED])
- constraint: monorepo boundaries fe/ be/ worker/ ai/ infra/ per AGENTS.md + docs/architecture/README.md — binding.
- constraint: Auth = Keycloak (OIDC Authorization Code + PKCE S256), tokens in memory (never localStorage), API validates JWT via JWKS (issuer/aud/azp). Realm+client roles → CurrentUser. [ADOPTED]
- constraint: be = FastAPI async, SQLAlchemy 2 async + asyncpg, Alembic (migrations = release step), thin routes → services/ modules. Python >=3.12,<3.15.
- constraint: async job path exists = be creates row → Redis list "weather-bridge:jobs" → worker BLPOP → calls be/src/ai runtime → writes Postgres. worker imports be via PYTHONPATH, duplicates ai_jobs Table via Core (independent deploy).
- constraint: online AI = be/src/ai (contracts.py InferenceProvider Protocol, litellm/mock providers, Langfuse tracer). offline = ai/ (train/eval stubs only). No train/GPU in API process (NFR5).
- constraint: fe = React 19 + Vite 8 + react-router 7 + @tanstack/react-query + Tailwind 4 + zod + react-hook-form. Generated OpenAPI client at fe/src/shared/api/generated.ts (currently stub; regen via make generate-contracts). No map lib present yet.
- constraint: infra = docker compose (base/dev/prod/ai), Keycloak realm+theme, litellm gateway (compose.ai), nginx proxy. observability/ + terraform/ are README-only scaffolds.

## Inherited from PRD/addendum (decided upstream — do NOT re-ask) [ADOPTED]
- constraint: Core hazards = flash flood + landslide only. Per-hazard SEPARATE trigger — flash flood = basin-integrated rain (FFG-style); landslide = I–D Guzzetti (α=2.20,β=−0.44 global, needs local calib) + antecedent. NEVER a shared trigger. (addendum §1,§3 reviewer fix)
- constraint: hazard score = [Σ wᵢ·norm(terrain_feature_i)] × Trigger(type); bin→1..5 (calibrated bins, NOT even [0,.2..]); project 5→2 tiers (prepare/go-now). Model level A (heuristic/AHP+I–D) for MVP; ML B/C = Roadmap.
- constraint: scoring must be deterministic + explainable (G3, NFR7): same input→same output, feature-contribution table. LLM strictly OUT of scoring path — only renders numbers→sentences.
- constraint: forecast rain = Open-Meteo/GFS/IFS (NOT ERA5). Historical rain (backtest) = ERA5/GPM IMERG. Terrain = SRTM 30m v3. Backtest = 25/7/2024 event, spatial check, NEVER train.
- constraint: RBAC 4 roles (admin / commune officer / village head / resident), data-scoped by village. Resident/household data = SIMULATED only, no real PII (Nghị định 13/2023). Alerts = 4 mandatory parts + countdown (FR7). Threshold table = configurable not hardcoded (FR9).

## Decisions (user-confirmed 2026-07-18) → become AD-n
- decision AD-1: offline static terrain feature-stack (ai/) vs online trigger-apply (be/src/ai+worker). Binds NFR5,FR1-3. Prevents geo libs in serving + nondeterministic recompute. [ADOPTED]
- decision AD-2: deterministic explainable scoring; LLM out of scoring path, only renders numbers→sentences. Binds G3,NFR7,FR2,FR11. Prevents unexplainable/LLM-altered risk. [ADOPTED]
- decision AD-3: per-hazard-type SEPARATE trigger (flood=FFG basin rain; landslide=I–D Guzzetti). Binds FR2. Prevents physically-wrong risk. [ADOPTED]
- decision AD-4: heatmap cross-boundary contract = (raster artifact in object storage + metadata row in Postgres) per (hazard_type,forecast_day); grid geometry (UTM48N/EPSG:32648, cell, bbox) defined once. FE never gets raw grid over API. Binds FR1,3,4. Prevents grid/projection disagreement + huge payloads. [ADOPTED]
- decision AD-5: refresh = scheduler enqueues job → worker executes full chain (score→raster→threshold→alert). Binds NFR4,FR3,6. Prevents request-thread compute + duplicate exec paths. [ADOPTED]
- decision AD-6: domain tables separate from generic ai_jobs; one writer per entity (worker writes run/layer/alert status via helpers, be owns schema+config). Binds FR6-10,17-19. Prevents two-owners/schema drift. [ADOPTED]
- decision AD-7: config split — versioned calibration artifact (weights,α/β,bins,stack version) immutable per run vs Postgres threshold_config (officer-editable, audited). Binds FR9,G3. Prevents non-repro runs + hardcoded thresholds. [ADOPTED]
- decision AD-8: RBAC data-scoping at service layer via Keycloak roles; resident/household rows all simulated=true, no real PII; token in memory. Binds FR17-19,NFR6. Prevents cross-village leak + PII capture. [ADOPTED]
- decision AD-9: alert invalid without 4 parts+countdown; 5→2 tier projection via one shared fn; action before numbers. Binds FR4,6,7,8. Prevents incomplete alerts + tiering drift. [ADOPTED]
- decision AD-10: backtest 25/7/2024 offline-only in ai/, never trains (model level A); reads same artifacts; results = internal reports. Binds G4,FR5. Prevents leakage/eval-train conflation. [ADOPTED]
- version: adds to ai/ = numpy/rasterio/scikit-learn/pyproj/rasterio (offline only); worker gets numpy (light array ops) not rasterio/gdal/sklearn; fe gets maplibre-gl; scheduler via APScheduler; object storage = S3-compatible (MinIO dev). Verify current versions at finalize.
- direction: paradigm = layered service core (ports & adapters, existing be pattern) + deterministic pipes-and-filters hazard pipeline + offline(batch)/online(serving) split.
